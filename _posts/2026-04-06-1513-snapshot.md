### 1. S-Oil (010950) — 정유 테마

| 항목 | 수치 |
|------|------|
| 현재가 | **118,100원** |
| 등락률 | **+6.01%** |
| 알고리즘 점수 | **22점** |
| 일 거래대금 | **약 1,015억원** |
| 외국인 연속 순매수 | **5일째** |
| 수급 유형 | DOUBLE_AC (거래대금 + 외국인 동시 집중) |

오늘 S-Oil에서 가장 눈에 띄는 신호는 두 가지입니다.

첫째, **정유 테마 신규 진입(lc=1)**. 테마 라이프사이클 카운터가 1이라는 뜻은 이 테마가 오늘 처음 레이더에 잡혔다는 의미입니다. 초기 진입 국면에서 수급이 쏟아지는 신선도가 높은 상황입니다.

둘째, **장 막판 거래대금 폭증**. 오전 333억원 수준이던 거래대금이 장 마감 직전 **1,015억원**으로 3배 이상 급증했습니다. 스마트 머니가 마감을 앞두고 집중 매수에 나선 패턴입니다.

외국인은 **5거래일 연속** 순매수를 이어가고 있어 단기 수급이 아닌 중기 방향성을 가진 움직임으로 해석됩니다.

### 2. SK이노베이션 (096770) — 정유 테마

| 항목 | 수치 |
|------|------|
| 현재가 | **123,200원** |
| 등락률 | **+4.23%** |
| 알고리즘 점수 | **22점** |
| 일 거래대금 | **약 750억원** |
| 기관 연속 순매수 | **6일째** |
| 수급 유형 | DOUBLE_AB (거래대금 + 기관 동시 집중) |

SK이노베이션은 기관의 **6거래일 연속** 순매수가 핵심입니다.

DOUBLE_AB 수급이란 거래대금 상위권(Set A)과 기관 순매수(Set B)가 동시에 포착된 것을 말합니다. 외국인은 아직 합류 전이지만, 기관이 6일 내내 담고 있다는 사실은 단순 단타가 아니라 목표 단가가 존재하는 구조적 매수임을 시사합니다.

여기에 SK온 차세대 배터리 재료 이슈가 겹치며 정유 + 2차전지 복합 모멘텀이 형성됐습니다. 거래대금도 오전 191억원에서 마감 전 **750억원**으로 급증했고, 1분봉·5분봉 패턴 필터도 정상 통과했습니다(**pattern 6점** 부여).

삼성SDI는 오늘 하루 거래대금만 **5,143억원**에 달합니다. 세 종목 중 압도적인 자금 규모입니다.

## NextTheme 알고리즘이 이 종목들을 선별한 이유

NextTheme 수급분석 엔진은 단순히 오르는 종목을 고르지 않습니다.

1. **교차 수급 분석** — Set A(거래대금) · Set B(기관) · Set C(외국인)가 동시에 잡히는 종목만 선별
2. **연속 순매수 추적** — 단발성 수급과 지속 수급을 구분해 중기 방향성 확인
3. **장 막판 거래대금 폭증 감지** — 스마트 머니의 마감 집중 매수 패턴 포착
4. **1분봉·5분봉 패턴 필터** — 눌림목 구조·거래량 확인 종목만 최종 통과
5. **매크로 경고 반영** — 오늘처럼 리스크가 높은 날에는 최소 점수 기준이 상향 적용

오늘은 매크로 경고 등급 + YELLOW 시장으로, 알고리즘이 자동으로 기준을 올려 3종목만 최종 선별했습니다.
