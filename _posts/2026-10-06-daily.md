오늘 증시는 한 방향으로 움직이지 않았습니다. 🙂 코스피는 **6,941.39포인트(-0.89%)** 로 7000선을 내줬고, 코스닥은 **919.92포인트(+2.98%)** 로 크게 올랐습니다. 대형 반도체주는 밀리고 중소형 성장주가 끌어올린 하루였습니다. 하루를 정리하며 전 거래일 선별이 실제로 어땠는지, 오늘 AI가 어떤 종목을 골랐는지 기록해 둡니다.

## 🔎 전 거래일 AI 선별, 오늘 아침 결과는 어땠을까?

종가베팅은 장 마감 무렵 종목을 고르고 다음 날 아침 시초가 부근에서 정리하는 방식입니다. 그래서 선별의 성적표는 **다음 날 아침 갭(전일 기준가 대비 시가 차이)** 으로 봅니다. 아래는 오늘 08:00~09:59 관측 기록이고, 모든 %는 **진입가 대비**입니다.

| 종목 | 아침 실현 갭 | 세션 내 최고 | 세션 내 최저 |
|---|---|---|---|
| 삼성중공업 | **-7.0%** | -5.5% | -7.2% |
| SK이노베이션 | **-1.0%** | -0.4% | -4.3% |

결과는 두 종목 모두 **진입가 아래에서 아침 시간을 보냈다**는 것입니다. 관측 시간 내내 최고점도 진입가에 닿지 못했습니다. 맞은 날만 적으면 기록이 의미가 없으니, 빗나간 날도 그대로 남깁니다.

오늘 선별의 **애프터마켓(정규장 이후 시간외 거래) 흐름**도 함께 보겠습니다. 이는 확정이 아닌 **잠정** 기록입니다. 실제 결과는 내일 아침에 나옵니다.

| 종목 | 잠정 갭 | 세션 내 최고 | 세션 내 최저 |
|---|---|---|---|
| 주성엔지니어링 | **+2.4%** | — | — |
| 삼성SDI | **+0.5%** | +0.5% | -0.7% |
| 삼성중공업 | **-7.6%** | -7.6% | -8.0% |

- 삼성SDI와 삼성중공업은 15:40~19:59 관측 구간의 진입가 대비 값입니다.
- 주성엔지니어링은 관측 구간 기록이 없어 갭 수치만 적었습니다.

## 📉 오늘 시장은 왜 엇갈렸을까?

지수만 보면 코스피와 코스닥이 반대로 움직였습니다.

| 구분 | 종가 | 등락률 |
|---|---|---|
| 코스피 | **6,941.39포인트** | -0.89% |
| 코스닥 | **919.92포인트** | +2.98% |
| 원/달러 환율 | **1,340.0원** | — |

최근 흐름을 보면 코스피는 9월 23일 **7,080.92포인트** 까지 올랐다가 10월 2일 7,003.74포인트로 7000선을 지켰습니다. 오늘 6,941.39포인트로 내려왔습니다. 코스닥은 9월 30일 855.91포인트에서 10월 1일 894.29포인트로 뛰었고, 오늘 919.92포인트까지 이어졌습니다.

**누가 사고 팔았나**를 보면 방향이 더 또렷합니다. (큰 투자기관을 뜻하는 기관, 해외 투자자를 뜻하는 외국인, 일반 투자자를 뜻하는 개인)

| 투자 주체 | 순매수(+)/순매도(-) |
|---|---|
| 외국인 | **-1.6조원** |
| 기관 | **+638억원** |
| 개인 | **+5,762억원** |

외국인이 약 1.6조원을 순매도했고, 개인이 이를 받아낸 모양입니다. 오늘 06시 브리핑 시점 기준으로는 간밤 미국장에서 다우 +0.18%, S&P500 +0.66%, 나스닥 +1.05%, 반도체 +0.28%로 3대 지수가 모두 올랐습니다.

## 🎯 오늘 AI는 어떤 종목을 골랐을까?

오늘 최종 선별에서 AI가 남긴 종목은 **주성엔지니어링**과 **삼성SDI** 두 개입니다. 시스템은 오늘 같은 날을 **신중하게 봐야 하는 구간**으로 분류했습니다. 코스피는 반도체 대형주 약세로 7000선을 내줬지만 코스닥으로 자금이 쏠렸다는 판단입니다. 아래는 추천이 아닌 **선별 기록**입니다.

### 주성엔지니어링 — 거래대금이 아침부터 오후까지 유지된 종목

AI가 남긴 근거는 반도체 장비 대장주로서 거래대금이 아침부터 터져 오후까지 유지됐고, 손바뀜(주인이 바뀌며 거래되는 정도)도 활발했다는 점입니다.

| 항목 | 내용 |
|---|---|
| AI 기록상 종가 / 등락률 | 276,500원 / **+16.7%** |
| 거래대금 / 시가총액 | 8,137억원 / 12.9조원 |
| 주도 테마 / 테마 내 순위 | LED장비 / 1위 |
| RSI(과열 정도를 보는 지표) / RVOL(평소 대비 거래량 배수) / 이동평균선 수렴 | 79.2 / 2.2배 / +0.3% |
| 52주 신고가 / 거래량 흐름 | 아님 / 중립 |
| 외국인 / 기관 순매수 | +9만 주 / +8,000주 |
| 호가 신호 | 매수벽 약함 |
| AI 종합 점수 | 45점 |

RSI가 79.2로 높은 편이라 단기간에 많이 오른 종목이라는 점은 같이 봐야 합니다.

### 삼성SDI — 외국인과 기관이 함께 산 2차전지 대장주

AI의 선별 근거는 2차전지 대장주이고 전고체 배터리 협력과 ESS(에너지저장장치) 수요 기대가 겹쳤으며, 오늘 외국인과 기관이 함께 순매수했다는 점입니다.

| 항목 | 내용 |
|---|---|
| AI 기록상 종가 / 등락률 | 574,000원 / **+8.5%** |
| 거래대금 / 시가총액 | 6,212억원 / 46.3조원 |
| 주도 테마 / 테마 내 순위 | 2차전지(나트륨이온) / 1위 |
| RSI / RVOL / 이동평균선 수렴 | 63.0 / 1.8배 / +0.1% |
| 52주 신고가 / 거래량 흐름 | 아님 / 주가 대비 거래량 흐름이 약함 |
| 외국인 / 기관 순매수 | +10만 주 / +4만 주 |
| 매출 증가율(전년 대비) | +32.2% |
| 최근 분기 실적(2026.09.) | 매출 4.0조원 / 영업이익 1,415억원 |
| AI 종합 점수 | 41점 |

두 종목을 나란히 보면 **성격이 다릅니다.** 주성엔지니어링은 상승 폭과 거래대금이 큰 대신 과열 지표가 높았고, 삼성SDI는 외국인·기관 순매수 규모가 더 컸지만 거래량 흐름이 가격을 따라오지 못했습니다.

## 🧭 오늘 제가 주목한 것

오늘 흐름에서 제가 눈여겨본 것은 **외국인이 1.6조원을 팔았는데도 코스닥은 3% 가까이 올랐다**는 점입니다. 지수 방향이 갈렸다는 건 대형주 중심으로 시장을 보면 놓치는 부분이 생긴다는 뜻이기도 합니다. 어느 쪽이 맞는다고 말할 수는 없습니다. 다만 오늘 거래대금 1~2위가 내리고 3위 이하 종목들이 크게 오른 것을 기록으로 남겨 둡니다. 내일 아침 오늘 선별 종목의 실제 갭이 어떻게 나오는지가 오늘 기록의 확인 지점입니다.
