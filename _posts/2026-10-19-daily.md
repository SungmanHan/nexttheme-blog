## AI는 왜 삼성SDI를 골랐을까?

오늘 최종 선별 결과는 **삼성SDI 1종목**입니다. AI는 "반도체에서 빠진 자금이 2차전지(ESS) 테마로 이동했고, 테마 거래대금이 오전 대비 2배로 늘었다"는 점을 근거로 기록했습니다. 반면 야간 미국 반도체 ETF가 -4.14%였던 만큼 **밤사이 흐름이 뒤집힐 위험**도 함께 적어 두었습니다.

| 항목 | 내용 |
|---|---|
| 종가 / 등락률 | 591,500원 / **+11.6%** |
| 거래대금 / 시가총액 | 9,844억원 / 47.6조원 |
| 주도 테마 / 테마 내 순위 | 2차전지(나트륨이온) / 1위 |
| RSI(과열 정도, 100에 가까울수록 과열) | 59.0 |
| 거래량 배율(평소 대비) | 2.2배 |
| 이동평균선 수렴 | +0.1% |
| 52주 신고가 | 아님 |
| 거래량 흐름(OBV) | 중립 |
| 외국인 순매수 | +12만 주 |
| 기관 순매수 | +7만 주 |
| 호가 신호 | 매수벽 약함 |
| 매출 증가율(전년 동기 대비) | +32.3% |
| 최근 분기 실적 (2026.09.) | 매출 40,388억원 / 영업이익 1,913억원 |
| AI 종합 점수 | 47점 |

눈에 띄는 점을 정리하면 이렇습니다.

- 🔹 **외국인(+12만 주)과 기관(+7만 주)이 같이 샀습니다.**
- 🔹 **거래량이 평소의 2.2배**로 늘었습니다.
- 🔹 RSI 59.0이라 과열권은 아니었고, 매수 호가에 쌓인 잔량은 **강하지 않은 편**(매수벽 약함)이었습니다.

이 내용은 매수 권유가 아니라 AI 선별 기록입니다. 애프터마켓에서는 진입가 부근(+0.1%~-1.3%)을 오갔고, 실제 결과는 내일 아침에 나옵니다.

## 오늘 이 흐름에서 제가 주목한 것은?

오늘 제가 눈여겨본 건 **지수 반등보다 자금의 이동 방향**입니다. 거래대금 1·2위는 여전히 반도체 대형주였지만, 큰 폭으로 오른 쪽은 배터리 관련주였습니다. 한 번 크게 빠진 시장에서는 "어디가 오르나"보다 "돈이 어디서 어디로 옮겨가나"를 보면 시장의 분위기를 읽기 쉽습니다.

한편 아침 복기에서 삼성중공업처럼 진입가와 크게 벌어진 종목이 나왔다는 점도 같이 기억해 두려고 합니다. 선별 기록은 맞은 날만이 아니라 틀린 날까지 쌓여야 의미가 있습니다. 📝
